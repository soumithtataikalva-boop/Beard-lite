# one-submenu-preserved: scene-offset control

One submenu, as in the failed test new, using existing labels and no script repairs. Unlike that test, every original animation/script/action/condition object retains its original offset and bytes. Only the root and growing main hairstyle section are relocated; the new export-table rows use the old root data span. Five new exports per scene are appended.

All original files, assets, scripts and localization are retained. Test 3's legacy encoder is used, and the working Test 3 bundle was reproduced byte for byte before creating these controls. No game-load result is known for these controls.

Install only this modNewHairstylesAndBeards folder in Mods, replacing other variants. Test the same save without overwriting it. Test flat-relocated first, then one-submenu-preserved separately. Report whether each loads. The submenu control intentionally reuses A pony tail as its heading label.
